GRASS — Передача смены
Финальная Windows-сборка 1.3.0

Что это:
Полноценное Windows-приложение на Electron. На компьютере сотрудника НЕ требуется Node.js, npm или исходники проекта.

Сборка:
1. Запустить BUILD_GRASS.bat на компьютере разработчика.
2. Получить dist\GRASS-Peredacha-smeny-Setup-1.3.0.exe.

Установка:
1. Запустить Setup.exe.
2. Выбрать папку при необходимости.
3. Установщик создаёт ярлык на рабочем столе и в меню Пуск.
4. После установки приложение запускается автоматически.

Данные:
SQLite база и резервные копии хранятся отдельно от установленной программы в AppData пользователя.
Путь данных: %APPDATA%\grass-shift-handover\data\
База: grass.db
Резервные копии: backups\

Обновление:
Установка новой версии поверх старой не должна удалять пользовательские данные. База находится вне папки установки.

Удаление:
Удаление программы через Windows не удаляет пользовательскую базу и резервные копии.

ВАЖНО:
На компьютере конечного пользователя нужен только готовый Setup.exe. Node.js и npm там не нужны.
