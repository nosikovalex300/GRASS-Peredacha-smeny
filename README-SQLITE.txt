GRASS — Передача смены
Этап 3: нормальная структура SQLite + резервные копии

Что изменилось:
- Данные приложения хранятся в нормальных SQLite-таблицах: tasks, task_history, technologists, settings, stats_archive, cleared_archive_ids.
- Старые данные из версии 1.1 автоматически мигрируются без ручного экспорта.
- Для совместимости интерфейс приложения продолжает работать через тот же внутренний storage-мост.
- Перед первой миграцией создаётся полный backup базы с пометкой pre-stage3.
- Далее автоматически создаётся ежедневная резервная копия.
- Хранится до 14 последних резервных копий.

Основная база:
%APPDATA%\grass-shift-handover\data\grass.db

Резервные копии:
%APPDATA%\grass-shift-handover\data\backups\

Важно:
Не удаляйте grass.db и папку backups, если хотите сохранить данные и возможность восстановления.
