GRASS — Передача смены 1.2.0

Этап 3: нормальная структура SQLite + резервные копии.
Интерфейс и рабочая логика приложения сохранены.

БЫСТРАЯ СБОРКА:
1. Установить Node.js LTS один раз.
2. Дважды щёлкнуть BUILD_GRASS.bat.
3. Если зависимости ещё не установлены, скрипт сам выполнит npm install.
4. Затем скрипт сам соберёт Windows-установщик.
5. После сборки автоматически откроется папка dist.

После первого запуска BUILD_GRASS.bat повторно npm install обычно не выполняется —
скрипт использует уже установленные зависимости.

Готовый установщик:
GRASS-Peredacha-smeny-Setup-1.2.0.exe

Данные:
%APPDATA%\grass-shift-handover\data\grass.db

Резервные копии:
%APPDATA%\grass-shift-handover\data\backups\

При первом переходе на этап 3 создаётся резервная копия старой базы до миграции.
Затем приложение автоматически поддерживает ежедневные резервные копии и хранит до 14 последних копий.
