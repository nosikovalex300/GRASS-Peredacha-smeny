Параметры приложения

Внешний видПлотность списка, предупреждение о передаче и уведомления — личные, у каждого технолога свои. Порог баннера — общий для площадки.
Плотность списка задачКомпактно: каждая задача в одну строку, подробности при наведении.
Предупреждать о передаче смены заПлашка смены станет жёлтой: «Через N мин передача».
Уведомление Windows до срока задачиО задачах, где вы исполнитель, а без исполнителя — о задачах вашей смены. О новой передаче вашей смене уведомление приходит всегда.
Красный баннер просрочкиЗадача с высоким приоритетом просрочена дольше этого времени — баннер видят все.
График сменОбщий для Ахтубы и Волжского. Цикл: 2 дня, выходной, 2 ночи, 3 выходных; смены по 12 часов.
Регламент и шаблоныПовторяющиеся задачи создаются сами в нужную смену. Шаблон без расписания — для кнопки «Из шаблона» в окне задачи. У каждой площадки свои.
Автоматически архивировать выполненныеВыполненные задачи будут перемещаться в архив автоматически.
Архивировать черезСрок отсчитывается с момента выполнения задачи.
ТехнологиДобавление и удаление пользователей приложения. Список общий для Ахтубы и Волжского.
Данные и резервные копииРезервное копирование, информация о базе и восстановление данных.
