# GRASS — Передача смены · Android-версия

Android-приложение (APK) на основе **того же `index.html`**, что и ПК-версия.
Логика смен, задач, передачи, архива и статистики — общая; любая правка в `index.html`
попадает и в ПК-версию, и в телефон.

## Как это устроено

| Файл | Что делает |
|---|---|
| `src/grass-mobile-bridge.js` | заменяет Electron (`preload.js` + `main.js`): хранилище, площадки, резервные копии |
| `src/grass-mobile.css` | вёрстка под экран телефона (десктоп не затрагивает) |
| `scripts/prepare-www.js` | собирает `www/` из корневого `index.html` |
| `scripts/patch-android.js` | иконки, заставка, версия, разрешения, подпись в Android-проекте |
| `scripts/make-icons.py` | делает иконки и заставку из `GRASS_icon.png` (при сборке, в `android-res/`) |
| `test/` | проверки скриптов сборки (`npm run check`) |
| `../.github/workflows/build-android.yml` | сборка APK в GitHub Actions |

## Данные на телефоне

- Своя база на телефоне, **с ПК не синхронизируется**. Площадки Ахтуба и Волжский разделены, список технологов общий — как в ПК-версии.
- Хранилище — IndexedDB внутри приложения.
- **Резервные копии** — JSON-файлы в `Документы/GRASS` на телефоне: каждый день автоматически + кнопка «Создать копию».
  Хранятся последние 30. Папка переживает удаление приложения.
- «Отправить копию» — отправить последнюю копию в Telegram, почту или на ПК.
- «Из файла…» — восстановить из любого файла копии (например, после переустановки или с другого телефона).
  Перед любым восстановлением автоматически делается страховочная копия.
- Кнопка «Назад» закрывает окна и меню, а не приложение.

## Сборка APK

Сборка идёт в GitHub Actions при пуше в ветку `android` (или вручную: Actions → *Build GRASS for Android (APK)* → Run workflow).
Готовый APK — в разделе **Artifacts** у запуска сборки.

**Ключ подписи.** Секрет репозитория `GRASS_ANDROID_SIGNING` (Settings → Secrets and variables → Actions)
содержит ключ, которым подписывается каждый APK. Пока ключ один и тот же, новые версии ставятся
**поверх** старой без потери данных. Если ключ потерять или поменять — новую версию поставить поверх не получится,
придётся удалять приложение (вместе с данными на телефоне). **Храните файл ключа в надёжном месте.**
Без секрета собирается тестовый APK с пометкой `-TEST`.

## Установка на телефон

1. Скачайте ZIP из Artifacts, распакуйте, перекиньте `.apk` на телефон.
2. Откройте файл → разрешите установку из этого источника → «Установить».
3. Обновление: так же ставите новый APK поверх — данные остаются.
